今日の天気 (11-14 Sat)

今日の天気は、おおむね晴れ時々曇りでしょう。 朝は清々しい快晴でスタートしますが、日中は雲が多めとなりそうです。ただ、雨の心配は全くありません。

良い一日をお過ごしください。
