今日の天気 (09-27 Sun)

9月27日、東京のお天気をお伝えします。

まず午前中は、雨や霧雨の降る時間帯が多いでしょう。特に早朝は少し雨脚が強まる可能性もありますので、お出かけには雨具が手放せません。

日中になると雨は一旦止み、晴れ間も広がりそうです。午後は気温が23度前後まで上がる見込みで、比較的過ごしやすいでしょう。

しかし、夕方から夜のはじめ頃にかけて、再び弱い雨が降る可能性がありますので、ご注意ください。

さて、日傘が必要かどうかの判断ですが、この日の最大UVインデックスは4.55と中程度ですが、一日を通しての日照時間は約16分と大変短くなっています。そのため、日焼け対策としての「日傘」は、特に必要ないでしょう。 ただし、雨の降る時間帯がありますので、雨具としての「傘」は必ずお持ちください。
