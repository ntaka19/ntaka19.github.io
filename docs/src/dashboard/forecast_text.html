今日の天気 (11-04 Wed)

皆さん、おはようございます！11月4日、東京のお天気をお伝えします。

今日は一日を通して雲に覆われた空模様となるでしょう。午前中は曇りが続きますが、午後の早い時間から雨が降り出し、夜にかけてしとしとと降り続く予報です。

気温は最高でも15度前後と、日中もあまり上がらず肌寒い一日となりそうです。最低気温は12度前後まで下がる見込みです。

日照時間はゼロで、太陽の光はほとんど届かないでしょう。紫外線指数は最大でも0.55と非常に低い値にとどまります。

このため、日傘は全く必要ありません。 午後からは雨が降りますので、お出かけの際は雨傘を忘れずにお持ちくださいね。
