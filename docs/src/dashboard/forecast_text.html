今日の天気 (10-03 Sat)

皆さん、こんにちは！10月3日（土）の東京の天気をお伝えします。

この日は一日を通してよく晴れるでしょう。 朝晩は最低気温17℃台とやや肌寒いですが、日中は最高気温が22℃台まで上がり、過ごしやすい秋の陽気となりそうです。雨の心配はありません。

さて、気になる日差しですが、UVインデックスは最大で5.65と「中程度から強い」レベルが予想されます。また、日照時間はたっぷり約10時間と、一日中日差しが降り注ぐ見込みです。

このため、外出の際には日差し対策が必須です。日傘や帽子、日焼け止めなどを活用し、紫外線対策をしっかりと行ってください。特に、日傘は日中の強い日差しを避けるのに非常に有効でしょう。
