今日の天気 (08-29 Sat)

東京地方、8月29日の天気をお伝えします。

この日は、一日を通してすっきりしない空模様となりそうです。弱い霧雨が降ったり止んだりする時間帯が多く、特に午前中から日中にかけては断続的に降り続くでしょう。午後には一時的にやや強まる霧雨となる時間帯もありそうです。 最高気温は25度台前半、最低気温は20度台前半と、蒸し暑さはいくぶん和らぎますが、ジメジメとした体感が予想されます。

さて、気になる日傘ですが、この日は日差し対策としての必要はございません。 一日の最大UVインデックスは0.6と非常に弱く、日照時間も全くありません。つまり、太陽の光がほとんど届かない一日となるため、日差しを避けるための日傘は不要です。 ただし、霧雨が降りますので、雨を避けるための折りたたみ傘などをお持ちになると安心でしょう。
